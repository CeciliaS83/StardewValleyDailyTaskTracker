Stardew Valley Daily Task Manager
9/22/26 - 11/24/26

## What it does
Stardew Valley Daily Task Manager manages what tasks you completed each day in Stardew Valley. Optimize the game by planning out each day before it happens with this task manager.
## One decision, and why
A record has many details because one task often has many different parts to it. For farming, there's seeds, watering can types, fetilizer, etc. For fishing, there's different fish types, different fishing rods, different bobbers.
